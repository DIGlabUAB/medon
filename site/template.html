How it works

It takes about ten minutes. No account and no install.

1

Describe the tool

{{N_QA}} questions about what it does, who uses it, how much it acts on its own and what data it touches. Then {{N_QB}} quick questions about the governance you already have.

2

See the risk tier

Low, moderate or high, with the answers that set it. If you are unsure of an answer, Medon assumes the safer option and flags it for you to confirm.

3

Get the checklist

Each item says what to do, what evidence shows it is done, who owns it and the source clause. Print it or save it as Markdown, CSV or JSON.

Use it at your institution

Your roles, committees and review schedules go in one file. Medon builds a single web page from it that you can host on any internal server.

You can also add your own local requirements, or new frameworks, as plain text files. See the README and contribution guide.

# Python 3.9 or later
pip install git+https://github.com/DIGlabUAB/medon

# get the template, then fill in your roles
curl -o my-institution.yaml https://raw.githubusercontent.com/DIGlabUAB/medon/main/src/medon/data/org.example.yaml

# build your planner page
medon web --org my-institution.yaml -o planner.html
