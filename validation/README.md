# Reviewer validation protocol

Two governance professionals review the checklists that Medon produces for 20 project types (one scenario each, maturity M2).

1. Each reviewer works alone and opens `reviewer workbook.csv`.
2. For every item, rate: 1 appropriate, 2 appropriate with changes, 3 not appropriate. Add a comment for 2 and 3.
3. In `missing items.csv`, list any item the plan should contain and does not. Name the source document if known.
4. Report the share of items rated 1 per reviewer, Cohen's kappa on the ratings, and the missing items grouped by theme.
5. Do not discuss ratings until both have finished. Resolve disagreements afterwards and record the outcome.

The scenarios are synthetic. No patient data is involved.
